# Musiqay 1.4.3

## التوافق والتثبيت
- رفع الإصدار إلى `1.4.3` و`versionCode 7`.
- تجهيز مسار بناء Release موقّع بدل إرسال Preview كتحديث.
- التحقق الآلي من package `com.musiqay.app` واسم/كود الإصدار والتوقيع وSHA-256 قبل تسليم APK.
- إضافة دعم فتح ملفات `audio/*` مباشرة من مدير الملفات عبر "فتح باستخدام موسيقاي".

## أسماء الملفات والبحث
- استخدام اسم الملف الحقيقي المخزن على الهاتف `DISPLAY_NAME` بدل إعادة تسمية الملف من Metadata.
- الإبقاء على الأسماء مثل `002.mp3` و`018.mp3` كما هي.
- البحث باسم السورة يطابق اسم السورة أو رقم ترتيبها في المصحف، مع دعم الأصفار البادئة مثل 2 / 02 / 002.
- منع المطابقة الرقمية الخاطئة مثل 118 عند البحث عن السورة رقم 18.
- إضافة اختصارات بحث واضحة لسورة البقرة والكهف وأرقامهما.

## الواجهة
- إضافة وضع AMOLED أسود حقيقي.
- تهدئة الخلفيات والإضاءات والـ gradients لتقليل الضوضاء البصرية.
- تحويل صفوف الملفات إلى قائمة Compact أخف بصريًا، مع إبراز الملف الجاري تشغيله فقط.
- تصغير Mini Player وتوحيد أحجام عناصره وإضافة شارة LIVE للراديو.
- منع تكرار Mini Player داخل شاشة الراديو أثناء عرض المحطة الحالية.
- تحسين Bottom Navigation بتقليل شدة المؤشر والحركة.
- ضغط مساحات الشاشة الرئيسية وتصغير كروت المكتبة والمضاف حديثًا.
- تحسين شاشة قيد التشغيل: غلاف أصغر، مسافات أدق، Seek bar أوضح، وأزرار نقل متوازنة.
- إظهار عدد العلامات المحفوظة بجوار زر العلامات.

## الراديو
- نقل إضافة محطة إلى زر + في رأس شاشة الراديو.
- تبسيط الإجراءات الثانوية.
- دمج المحطات المتكررة بصريًا مع الحفاظ على المحطة الحالية أو المفضلة عند وجود تكرار.
- إضافة حالة LIVE داخل بطاقة المحطة الحالية.
