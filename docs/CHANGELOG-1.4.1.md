# Musiqay 1.4.1 — premium polish & smoothness

- Cleans noisy local metadata such as website prefixes, filename extensions and decorative separators.
- Cleans remote radio station names and preserves safe fallbacks.
- Reduces heavy gradients, outlines and glow to improve hierarchy and readability.
- Makes song rows, home shortcuts, playlists, library groups, settings and the mini player denser and more consistent.
- Moves local-track mini-player progress to the top edge for quicker scanning.
- Removes the currently playing radio station from the repeated station list and compacts radio controls.
- Uses selected/unselected navigation icon treatments and lighter active indicators.
- Adds stable lazy-layout content types to improve composition reuse while scrolling.
- Refines Now Playing artwork footprint, controls and action layout.
- Adds unit coverage for metadata/radio-name normalization.

Build target: preview package `com.musiqay.app.preview`, version 1.4.1-preview, versionCode 5.
