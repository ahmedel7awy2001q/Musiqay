# موسيقاي — Musiqay

مشغل موسيقى عربي محلي لنظام Android، بواجهة RTL حديثة ومصمم للعمل بدون حساب وبدون رفع مكتبة المستخدم إلى أي خادم.

## الإصدار 1.0

- واجهة عربية كاملة واتجاه RTL.
- قراءة ملفات الصوت من الهاتف عبر MediaStore.
- تشغيل بالخلفية باستخدام Jetpack Media3 / ExoPlayer.
- تحكم من إشعار الوسائط وشاشة القفل وأجهزة Bluetooth المتوافقة.
- شاشة تشغيل كاملة مع غلاف الألبوم وشريط التقدم والسابق/التالي والعشوائي والتكرار.
- قائمة انتظار قابلة لإعادة الترتيب والإزالة.
- المفضلة وحفظها محليًا.
- قوائم تشغيل محلية مخصصة وحفظها عبر Room.
- البحث في الأغاني والفنانين والألبومات والمجلدات.
- استعراض المكتبة حسب الفنان / الألبوم / المجلد.
- مؤقت إيقاف 15/30/45/60/90 دقيقة.
- فتح لوحة المؤثرات الصوتية الخاصة بالنظام عند توفرها.
- الوضع الداكن والفاتح وألوان Android الديناميكية.
- لا يحتاج إنترنت لتشغيل الموسيقى.
- GitHub Actions يبني APK ويولد SHA-256 تلقائيًا.

## الخصوصية

التطبيق محلي. ملفات الموسيقى نفسها لا تُنسخ إلى قاعدة بيانات التطبيق ولا تُرفع إلى GitHub أو إلى خدمة خارجية. قاعدة Room تحتوي فقط على معرفات المفضلة وقوائم التشغيل المحلية.

## التقنية

Kotlin • Jetpack Compose • Media3 / ExoPlayer • MediaSessionService • MediaStore • Room • DataStore • Material 3

الحزمة: `com.musiqay.app`

الحد الأدنى: Android 8.0 (API 26)

الهدف: Android API 36

## البناء

GitHub Actions يبني:

`app/build/outputs/apk/debug/app-debug.apk`

ويُنشئ ملف SHA-256 بجواره.

المشروع مثبت على Android Gradle Plugin 8.13.2 وGradle 8.13 وJDK 17 لتقليل تغييرات الإصدارات غير الضرورية.

## كلمات الأغاني

موسيقاي لا يرسل أسماء الأغاني إلى خدمات خارجية لجلب الكلمات تلقائيًا. هذا يحافظ على خصوصية مكتبة المستخدم.
