# موسيقاي — Musiqay 1.4.0

مشغل موسيقى عربي لنظام Android مع راديو عبر الإنترنت، دون حساب ودون رفع مكتبة المستخدم إلى أي خادم.

## التطوير الحالي

- تبويبة راديو مصرية: روابط أساسية منتقاة ودليل Radio Browser قابل للتحديث مع نسخة محلية للمحطات.
- بحث عربي وتصنيفات ومفضلة منفصلة للمحطات وآخر محطة، مع حفظ قائمة الأغاني وموضعها أثناء الراديو.
- بث في خدمة Media3 الحالية، ودعم MP3/AAC/HLS ومؤقت النوم وإعادة الاتصال المحدودة.
- الراديو متاح دون إذن قراءة أغاني الهاتف. إيقاف البث يوقف تحميله، والاستكمال يعود للبث الحي.
- رئيسية مختصرة مع استكمال آخر استماع وتشغيل كل الأغاني.
- مكتبة تجمع الوصول إلى الأغاني والفنانين والألبومات والمجلدات.
- شاشة تشغيل متكيفة مع الشاشات الصغيرة والوضع الأفقي وغلاف الألبوم.
- مشغل مصغر متاح أثناء استعراض الفنانين والألبومات والمجلدات والقوائم.
- فصل تحديث زمن الأغنية عن شاشات المكتبة وتقليل إعادة الحساب والحفظ.
- تحديث المكتبة تلقائيًا عند تغيّر ملفات الصوت، مع حالة تحميل وخطأ وإعادة محاولة.
- بحث في الخلفية مع تأخير قصير أثناء الكتابة ودعم التشكيل واختلافات الألف.
- تعريف المجلدات بمسارها الكامل وتجميع الألبومات بمعرفها.
- استمرار احترام المجلدات المخفية سابقًا بالاسم. الخيارات الجديدة تخص المسار المختار فقط.
- انتظار بالسحب لإعادة الترتيب، واختيار النسخة الصحيحة من الأغنية المكررة، وإزالة مع تراجع وتفريغ مؤكد.
- حفظ الانتظار الفارغ وعدم إعادة قائمة قديمة بعد تفريغها، واستعادة موضع النسخة المختارة.
- قوائم تشغيل مع إعادة تسمية وتأكيد الحذف وغلاف وعدد الأغاني والمدة.
- مشاركة الملف الصوتي نفسه مع منح إذن قراءة مؤقت للتطبيق المستقبِل.
- فتح المؤثرات باستخدام جلسة الصوت الفعلية عند توفر لوحة نظام متوافقة.
- خط Noto Sans Arabic مضمّن، وأيقونة M مستوحاة من الموجة الصوتية، ونسخة أحادية اللون وأيقونة إشعار موحدة.
- تقليل حركة اختياري، وحماية عمليات المفضلة وإنشاء القائمة بمعاملات Room.
- العودة من إعدادات الأذونات تحدث حالة الوصول والمكتبة.

## الحفاظ على البيانات

- الحزمة باقية `com.musiqay.app`، واسم القاعدة `musiqay.db` وإصدارها `1`.
- كيانات القاعدة وأعمدتها لم تتغير. لا يوجد حذف للبيانات أو destructive migration.
- لا يُعاد بناء الانتظار بسبب كل تحديث للمكتبة؛ تظل جلسة التشغيل الحالية محفوظة.
- المجلد المخفي يُستبعد من المكتبة والجلسة المستعادة. الانتظار الحالي لا يُحذف تلقائيًا عند الإخفاء.
- تثبيت تحديث فوق النسخة الموجودة يحتاج مفتاح التوقيع نفسه. لا تغيّر المفتاح ولا تحذف التطبيق أو بياناته من أجل التحديث.

## التحقق

```bash
./gradlew :app:testDebugUnitTest :app:lintDebug
```

تغطي اختبارات LibraryRules الهوية الكاملة للمجلدات والخيارات القديمة، والبحث العربي، واستعادة الأغاني المكررة والملفات المفقودة والانتظار الفارغ. يجب أيضًا اختبار التفاعل على جهاز قبل اعتماد الإصدار.

قائمة اختبار الجهاز: `docs/DEVICE-CHECKLIST-1.4.md`.

## البناء

Kotlin / Jetpack Compose / Media3 / Room / DataStore. Android 8.0+، compile/target SDK 36، JDK 17، Gradle 8.13، AGP 8.13.2.

دفع فرع التطوير لا يبدأ GitHub Actions. لا تدمج إلى main قبل اجتياز الفحوص واعتماد البناء.

عند طلب البناء، يدعم workflow اختيار `debug` أو `release` يدويًا. Release يستخدم تصغير الكود والموارد، ويتطلب أسرار التوقيع الموجودة الخاصة بمفتاح التحديث الصحيح:

- `MUSIQAY_KEYSTORE_BASE64`
- `MUSIQAY_KEYSTORE_PASSWORD`
- `MUSIQAY_KEY_ALIAS`
- `MUSIQAY_KEY_PASSWORD`

لا ينشئ workflow مفتاحًا جديدًا ولا يرفع المفتاح داخل المستودع أو artifacts. للبناء المحلي الموقّع استخدم متغير `MUSIQAY_KEYSTORE_PATH` بدل base64 مع متغيرات كلمات المرور والاسم السابقة.

إذا لم يتوفر مفتاح النسخة القديمة، يمكن بناء نسخة اختبار منفصلة بـ `./gradlew -PpreviewBuild=true :app:assembleDebug`. تظهر باسم «موسيقاي • تجربة» وتستخدم `com.musiqay.app.preview`. لا تعد تحديثًا للنسخة القديمة؛ بياناتها منفصلة. التحديث الحقيقي يحتاج شهادة التوقيع المطابقة.

## الخصوصية والتراخيص

تشغيل أغاني الهاتف محلي. ملفات الأغاني لا تُنسخ إلى قاعدة البيانات ولا تُرفع إلى GitHub أو خدمات كلمات أغاني. المشاركة تتم فقط بطلب المستخدم عبر تطبيق المشاركة الذي يختاره.

الراديو يتصل بخادم دليل Radio Browser عند فتح تبويبته للتحديث، وبخوادم الشعارات والمحطة المختارة. هذه الخوادم تستقبل طلبات الشبكة المعتادة ومنها عنوان IP؛ لا يرسل موسيقاي ملفات الأغاني أو قائمة المكتبة إليها. أسماء المحطات والمفضلة محفوظة محليًا. بعض البثوث تستخدم HTTP، وتوفر المحطات يعتمد على جهات البث. التفاصيل ومصادر الروابط في `docs/RADIO-IMPLEMENTATION.md`.
